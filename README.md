# Java Fundamentals & Mini-Projects ☕

This repository is a collection of early Java projects I developed while mastering core programming concepts, data structures, and Graphical User Interfaces (GUIs). 

These projects served as my foundational stepping stones before transitioning into modern web frameworks and enterprise backend development.

## 🗂️ Project Directory

### 1. Burger Shop CLI (`/burger-shop-cli`)
A purely console-based application to manage fast-food orders.
* **Focus:** Procedural programming, standard I/O, and custom sorting algorithms (Bubble Sort).
* **Key Feature:** Manages order states and calculates best customers using parallel array data structures.

### 2. Student Management System (`/student-management-gui`)
A desktop application built with Java Swing for managing student records.
* **Focus:** Object-Oriented Programming (OOP) and UI form design.
* **Key Feature:** Full CRUD (Create, Read, Update, Delete) capabilities for student data management.

### 3. Train Ticket Reservation (`/train-reservation-gui`)
A multi-window desktop application simulating a railway booking platform.
* **Focus:** State management across multiple GUI windows.
* **Key Feature:** Includes a user authentication gateway (`LogIn.java`) and transactional seat booking logic.

## 💻 How to Run
* **CLI Project:** Navigate to the specific folder and run the `.java` file directly from the terminal.
* **GUI Projects:** These utilize NetBeans `.form` files. It is recommended to clone the repository and open the specific project folder directly within Apache NetBeans to view the visual layouts.
